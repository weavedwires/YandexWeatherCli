# YandexWeatherCli

CLI для прогноза погоды через Yandex Weather API. Выводит машиночитаемый
pipe-разделительный CSV и вызывается одной командой.

## Когда использовать

Активируй скилл, когда пользователь просит:

- погоду / прогноз на сегодня, завтра, несколько дней;
- температуру, «ощущается как», ветер, влажность, осадки;
- погоду в конкретном городе или месте.

## Предварительные требования

- Java 17+ (`java -version`).
- API-ключ в файле `api-key.txt` в каталоге установки `~/.local/share/yweather`
  (или в текущей директории).
- `places.json` с любимыми местами — там же (поставляется с релизом).

Если `api-key.txt` отсутствует, команда завершится с сообщением
`Файл api-key.txt не найден...` — сообщи пользователю, что нужен ключ.

## Основной вызов

Всегда одна команда, указывай только место:

```bash
yweather --place <название>
```

Примеры:

```bash
yweather --place Екатеринбург
yweather --place Москва --days 3
yweather --place Москва --hours 12-22
yweather --lat 56.83 --lon 60.60
```

## Флаги

| Флаг | Описание |
|------|----------|
| `--place <name>` | Место из `places.json` (русское или английское имя) |
| `--lat`, `--lon` | Координаты, если места нет в `places.json` |
| `--days <N>` | Количество дней прогноза (по умолчанию 1) |
| `--hours <N\|N-M>` | Один час (`5`) или диапазон (`12-22`). По умолчанию все часы |
| `--fields <list>` | Какие поля выводить, через запятую |

Флага `--compact` нет — вывод всегда машиночитаемый.

По умолчанию `--fields`:
`hour,temp,feels_like,condition,prec_strength,prec_type,wind_speed,wind_gust,humidity`.

## Формат вывода

Pipe-разделительный CSV с заголовком `date|field1|field2|...`,
по строке на каждый час:

```
date|hour|temp|feels_like|condition|prec_strength|prec_type|wind_speed|wind_gust|humidity
2026-06-14|0|+12|+10|Ясно|0|none|2.1|4.0|78%
2026-06-14|1|+11|+9|Ясно|0|none|2.3|4.2|80%
```

Разбирай первую строку как заголовок, остальные — как данные.
`date` — дата прогноза, `hour` — час от 0 до 23.

## Доступные поля

| Поле | Тип | Описание | Пример |
|------|-----|----------|--------|
| `hour` | число | Час от 0 до 23 | `14` |
| `temp` | °C | Температура воздуха | `+18`, `-5` |
| `feels_like` | °C | Ощущаемая температура | `+16` |
| `condition` | строка | Погодное явление (по-русски) | `Ясно`, `Дождь`, `Гроза с градом` |
| `prec_strength` | число | Интенсивность осадков (0 = нет, >0 = мм/ч) | `0.0`, `1.5` |
| `prec_type` | enum | Тип осадков: `none` / `rain` / `snow` | `rain` |
| `wind_speed` | м/с | Скорость ветра | `3.2` |
| `wind_gust` | м/с | Порывы ветра | `7.1` |
| `humidity` | % | Влажность | `65%` |
| `wind_dir` | строка | Направление ветра (румбы) | `С`, `ЮЗ`, `СВ` |

Примечания:

- `temp` всегда со знаком: `+18`, `-5`.
- `prec_type`: `none` — без осадков, `rain` — дождь, `snow` — снег.
- `wind_dir` — румбы: `С, СВ, В, ЮВ, Ю, ЮЗ, З, СЗ`.
- `prec_strength` — сырое значение API: 0 = сухо, >0 = мм/ч.

## Любимые места (places.json)

Агент может добавлять и править любимые места в `places.json` **в каталоге установки**
`~/.local/share/yweather` (или в текущей директории). Формат — массив объектов:

```json
[
  {
    "names": ["Москва", "Moscow"],
    "lat": 55.755864,
    "lon": 37.617698
  },
  {
    "names": ["Лондон", "London"],
    "lat": 51.507351,
    "lon": -0.127696
  }
]
```

Правила:

- `names` — массив имён (русское, английское и алиасы). Поиск идёт по любому
  имени без учёта регистра, поэтому алиасов лучше указывать побольше.
- `lat` / `lon` — координаты (можно числом или строкой).
- Первое имя в `names` используется как отображаемое в списке доступных мест.

После правки проверь, что JSON валиден, и что место находится:

```bash
yweather --place "<новое имя>"
```

### Добавить место

1. Найди координаты города.
2. Добавь объект в `places.json` (не ломая JSON).
3. Проверь вызовом `yweather --place <имя>`.

## Обработка ошибок

| Сообщение | Причина / действие |
|-----------|--------------------|
| `Место "..." не найдено в places.json` | Нет такого имени. В stderr печатается список доступных мест — выбери из него или добавь место в `places.json`. |
| `Файл api-key.txt не найден...` | Нужен API-ключ в каталоге установки `~/.local/share/yweather` или в текущей директории. |
| `Укажите --place <название> или --lat <lat> --lon <lon>` | Не передано место или координаты. |

Вывод с ошибками идёт в stderr; данные — в stdout.

## Пример использования агентом

Пользователь: «Какая погода в Москве завтра?»

```bash
yweather --place Москва --days 2 --hours 12-18
```

Агент разбирает CSV и формирует человекочитаемый ответ, не пересказывая
заголовок и не показывая сырые разделители `|` без обработки.
